# Harmony Hub Frontend

Music collaboration platform frontend built with React and TypeScript.

[![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?logo=typescript&logoColor=white)](https://www.typescriptlang.org/)
[![React](https://img.shields.io/badge/React-20232A?logo=react&logoColor=61DAFB)](https://reactjs.org/)

## Overview

The frontend for Harmony Hub, a music collaboration platform enabling musicians to connect, share, and create together. Built as a responsive single-page application.

## Features

- User profiles and discovery
- Real-time collaboration sessions
- Music library management
- Responsive Material-style UI

## Tech Stack

- **Framework**: React
- **Language**: TypeScript
- **Styling**: CSS

## Setup

```bash
npm install
npm start
```

Runs on [http://localhost:3000](http://localhost:3000).
